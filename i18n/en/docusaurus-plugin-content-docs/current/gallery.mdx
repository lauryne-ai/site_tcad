# Results gallery

Example outputs produced by The APE Bridge after a full calculation.

## Carbon (diamond, Fd-3m)

**Extracted properties:**
- ε₀ ≈ 6.74 (experimental: 6.72)
- ω_p ≈ 28.9 eV
- Isotropy: |ε_x − ε_y| < 0.01 %
- Zero-crossing (plasma frequency) at ~12.3 eV

![C — Real dielectric function dispersion εᵣ(ω)](/img/gallery/c_dielectric_dispersion.png)

High-resolution PNG figures are generated in `plots/`:

```bash
qe-plot C
# → plots/C_dielectric_dispersion.png
```

## TCAD validation — SiGe

1D device simulation results obtained with `qe-tcad` from SiGe properties exported by the pipeline.

### Diode

Forward-bias I–V characteristic and electrostatic potential profile at equilibrium.

![TCAD validation — SiGe (diode): I-V characteristic and equilibrium potential](/img/gallery/sige_diode.png)

```bash
qe-tcad SiGe diode
```

### NPN transistor

I–V characteristic and equilibrium potential profile for a SiGe NPN transistor.

![TCAD validation — SiGe (NPN transistor): I-V characteristic and potential profile](/img/gallery/sige_transistor.png)

```bash
qe-tcad SiGe transistor
```

## Reproduce these results

```bash
qe-bridge SiGe
qe-plot SiGe
qe-tcad SiGe diode
qe-tcad SiGe transistor
```

See [Usage](/docs/setup/usage) for the full guide.
