## Prérequis rapides

| Composant | Version minimale |
|-----------|------------------|
| Python | 3.10+ |
| Quantum ESPRESSO | 7.0+ (`pw.x`, `epsilon.x`) |
| MPI | OpenMPI ou MPICH (recommandé) |
| Espace disque | ~20 GiB pour calculs complets |
| Clé API | `MP_API_KEY` personnelle (créer sur Materials Project) |

:::tip Docker
Si vous préférez éviter l'installation manuelle de QE, consultez la section [Docker](/docs/setup/installation#option-docker) dans le guide d'installation.
:::
