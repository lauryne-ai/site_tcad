# Ressources externes

Liens utiles pour approfondir la DFT, Quantum ESPRESSO et l'ingénierie TCAD.

## Quantum ESPRESSO

- [Site officiel](https://www.quantum-espresso.org/)
- [Manuel utilisateur](https://www.quantum-espresso.org/users-manual/)
- [Téléchargement QE](https://gitlab.com/QEF/q-e)
- [Tutoriel QE (pranabdas)](https://pranabdas.github.io/espresso/) — inspiration pour ce site
- [Ressources QE](https://pranabdas.github.io/espresso/resources)

## Théorie & articles

- Gonze & Lee (1997) — *Phys. Rev. B* 55, 10355 — Réponse diélectrique en DFPT
- [QUANTUM ESPRESSO: a modular and open-source software project](https://www.quantum-espresso.org/papers)

## Bases de données matériaux

- [Materials Project](https://materialsproject.org/) — structures cristallines et propriétés
- [Materials Project API](https://docs.materialsproject.org/) — clé `MP_API_KEY` requise

## TCAD

- [Synopsys Sentaurus](https://www.synopsys.com/silicon/tcad.html) — documentation Sentaurus Device
- [DEVSIM](https://devsim.org/) — simulateur open-source utilisé pour la validation 1D
- [nanoHUB](https://nanohub.org/) — plateforme de simulation nanotechnologie ; nos sorties diode et transistor y ont été comparées pour validation

## Livres recommandés

- *Density Functional Theory: A Practical Introduction* — Sholl & Steckel
- *Materials Modelling using Density Functional Theory* — Feliciano Giustino
- *Electronic Structure: Basic Theory and Practical Methods* — Richard M. Martin
